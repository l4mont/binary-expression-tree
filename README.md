# CSC 223 Binary Expression Tree

This Python program builds a linked binary expression tree from postfix input, displays infix and postfix forms, and evaluates the result.

Open BinaryExpressionTree.pyproj in Visual Studio with the Python workload installed.

Run the reused stack's self-checks with:

    python stack.py

Run the sample driver and unit tests:

    python main.py
    python -m unittest -v test_binary_expression_tree
